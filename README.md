# OrthoSense-AI

## AI-Powered Orthopedic Monitoring System

OrthoSense-AI is an intelligent orthopedic monitoring project that uses sensor simulation and machine learning to analyze patient-related data.

## Features

- Sensor data simulation
- Machine learning prediction
- Patient dashboard
- Medical history tracking
- SQLite database
- Web-based dashboard

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning

## How to Run

```bash
pip install -r requirements.txt
python app.py
